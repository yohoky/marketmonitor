    板块指数 0
    宽基 / 板块指数勾选即加入当前列表；同样参与滚动 / 跳动与异动提醒（含邮件推送）。
    异动提醒（当前列表）
    提醒市场 只在开盘时段提醒、收盘后 / 夜间 / 周末不打扰。A股 09:25–11:35 / 12:55–15:05；港股 09:00–12:00 / 13:00–16:00。
    涨幅、跌幅阈值可分别设置（例如涨 3.9% / 跌 5%）。取消勾选即关闭该方向提醒。
    触发后：系统通知 + 提示音 + 该列表小组件对应行闪烁。冷却期内同一只不重复打扰。
    邮件推送 · 发件账号（全部列表共用）
    465 勾选；587 / 25 不勾选（会自动 STARTTLS 加密）
    收件邮箱槽位（1~5 个）
    这里是"给谁发"的地址池。每个地址可单独启用 / 停用，下面再由每个列表挑选自己发给哪几个槽位。
    填完地址记得把该行右侧的「启用」勾上（1 号槽默认已启用），没勾的槽位不会被投递。
    当前列表发给
    % 才发邮件
    勾选后，每隔设定分钟数把当前列表的全部行情汇总成一封邮件发出（间隔 1~1440 分钟）。
    汇总邮件是手机友好的卡片排版，涨红跌绿；同时附带纯文本版，老邮箱客户端也能正常看。
    与异动推送互不影响：异动是"到阈值才发"，汇总是"到点就发"，两条通道各自独立计时。
    授权码不是登录密码：QQ / 163 邮箱需先到邮箱「设置 → 账户」开启 SMTP 服务并生成授权码。
    触发后异步发信，不影响行情刷新；发送记录见程序目录 maillog.txt，失败详情见 error.log。
    配置导出 / 导入
    把全部监控列表与邮件设置导出成一个 JSON 文件，换台电脑装上程序后导入即可复现，不用重新配一遍。
    导入会覆盖当前全部配置（原配置会自动备份为 config.ini.bak）。
    不含授权码时，导入到新机器后需要重新填一次授权码才能发邮件。
    导出文件里会包含收件邮箱地址，请注意存放位置，不要随意转发。
