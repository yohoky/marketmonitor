# Marketmonitor

**Windows 桌面常驻的 A 股 / 港股 悬浮小组件** —— **多个监控列表各自一个悬浮窗**（股票 / 基金 / 指数分开盯）、实时行情、异动提醒（系统通知 / 提示音 / **邮件推送** / **邮件定时汇总**），收件邮箱 1~5 个可分别指定，配置一键导出导入，客户端自动更新，背景 / 文字透明度分别可调、黑白摸鱼模式，右键即配置，装完即用。

## ✨ 它是什么

一个常驻在 Windows 桌面（默认右下角）的透明小卡片，实时显示你自选股票的**名称 / 现价 / 涨跌幅**：

- **多个监控列表 = 多个独立小窗**：列表 1 盯自选股、列表 2 盯板块指数、列表 3 盯基金……各自位置、尺寸、透明度、提醒阈值、收件人都可以不一样
- 多只股票同屏，可**平滑滚动**或**逐页跳动**两种展示方式自由切换
- 涨用**红**、跌用**绿**（遵循 A 股惯例）
- 后台每 30 秒静默刷新一次实时行情，全程不打断你
- 完全透明可叠加在任意窗口之上，或调成半透明"摸鱼"不刺眼

## 🚀 安装（最简单）

1. 到 [Releases](../../releases) 页面，下载最新的 `Marketmonitor-Setup-x.x.x.exe`（一键安装包，约 70MB）。
2. 双击 → 自动安装到当前用户目录（**无需管理员权限**）→ 自动生成**桌面 + 开始菜单**快捷方式 → 装完自动启动。
3. 想卸载：设置 → 应用 → 搜 "Marketmonitor" → 卸载即可（会一并清理配置）。

> 便携版不安装、免依赖，也可以直接把发布包里的程序文件夹拷到任意 U 盘即插即用。

> 🔄 **升级不用手动下载**：程序启动 20 秒后会静默检查一次新版本（之后每 24 小时一次），有新版会弹通知；也可以在「设置 → 关于与更新」点「检查更新」→「下载并安装新版」，程序会下载安装包并拉起安装向导。

| 📧 邮件推送 | 触发异动后把明细发到该列表指定的收件人。**邮件阈值按列表各设一套**（v1.5.5）：每个列表自己决定是**跟随本列表异动阈值**（一处改、两处生效），还是**单独设一个邮件阈值** —— 典型用法是「异动 3.9% 就闪屏 / 弹通知，邮件等到 6% 才发」，小波动不刷屏、只有大涨大跌进邮箱。勾选跟随时两个输入框会置灰但实时回显本列表的异动阈值，不跟随时才可编辑；老配置里的全局阈值会自动继承到每个列表，**无损升级**、不用重配；支持 465(SSL) 与 587(STARTTLS)，账号授权码只存在本机 `config.ini`，不上传任何服务器；邮件正文是**卡片式彩色 HTML**（大号涨跌幅 + 名称 / 代码 / 现价 / 触发阈值 / 时间详情表，涨红跌绿，手机友好），另附纯文本版兜底 |
| 🗂 邮件定时汇总 | **按列表独立开关**，两种方式任选：**按固定时点**（默认 09:30 / 09:35 / 09:55 / 14:35 / 14:48 / 14:54，可在设置页自行增删，逗号分隔）或**按间隔**（每隔 N 分钟，1–1440，默认 30）。**两种方式都只在大盘开盘窗口内推送**（上午 09:25–11:35、下午 13:00–15:05）：**11:35–13:00 午休期间一封都不发**，收盘后（>15:05）与夜间也不发（v1.5.6 修复：此前「按间隔」模式漏了这套时间窗，收盘后仍会按间隔持续刷邮件）；某个时点没赶上会在**同一交易时段内补推最近一次**，跨时段与夜间不补。排版是**手机友好的 HTML 卡片**（竖排、不用横滑、涨红跌绿 + 涨跌家数概览条），同时附带纯文本版兜底；与异动推送**两条通道互不影响**，另提供「立即给当前列表发一封汇总」手动验证；**不论用哪种方式，上午收盘 11:30 与下午收盘 15:00 都会各发一封收盘总结**（额外附涨 / 跌 / 平家数、平均涨跌幅与领涨 / 领跌前三的收盘小结） |
| 💾 配置导出 / 导入 | 一键把**全部列表 + 邮件设置**导出成一个 JSON，换台电脑装上程序后导入即可复现，不用重新配一遍；导入前会自动把原配置备份成 `config.ini.bak`。可选是否包含邮箱授权码 |
| 🔄 客户端自动更新 | 用 GitHub Releases 当更新服务器（零额外依赖）：启动 20 秒后静默检查、之后每 24 小时一次，有新版弹系统通知；设置页可手动「检查更新 → 下载并安装新版」（下载后拉起官方安装向导，不会静默覆盖）|
| 🎚 背景透明度 | 0.05–1.0 可调，**只淡卡片底色、文字不受影响**（低透明度下自动收敛光晕，不发虚）|
| 🔅 文字透明度 | 0.05–1.0 **独立可调**，只淡文字和数字（含状态栏），卡片轮廓保持原样；与背景透明度互不干扰，可组合出"只剩淡淡一层数字"的深度摸鱼效果 |
| 🌗 黑白模式 | 打开后涨跌**不再用红绿**，改深浅灰（涨深灰 / 跌浅灰），异动闪烁也一并转为中性灰，屏幕前不显眼；一行开关，立即生效 |
| 📐 尺寸 | 宽 / 高**双向实时**生效，高度决定同屏行数（高 140≈3 行，高 400≈12+ 行）|
| 🧭 屏幕位置 | 九宫格一键归位（左上 / 正中 / 右下 ……），也可随意拖动；**默认右下角**。新列表会自动避开已有窗口找空位 |
| 🔄 展示方式 | `滚动` 平滑位移 / `跳动` 整页切换，实时切换 |
| ⏱ 动画节奏 | **滚动速率**与**跳动间隔**分别可调（滚动每行 0.8–15 秒、跳动每页 1–20 秒），两个模式各记各的，互不覆盖 |
| 📌 置顶 | 一键让小组件常在最上层（按列表分别设置）。**被其它窗口遮挡时能自动恢复**（v1.5.7 修正）：窗口显示 / 获焦 / 改置顶设置 / 关闭设置页时都会重新下发置顶，后台另有周期自愈，托盘还提供「重新置顶（被遮挡时点这里）」手动兜底 |
| 🖱 拖拽 | 按住卡片任意非按钮区域拖动到任意位置，松手自动保存，下次启动仍在原地 |
| ⚙️ 设置窗口 | 右键小组件即可打开；默认高度为**屏幕高度的一半**（v1.5.7），从上往下排布，打开即用、不必手动拉伸 |
| ⏸ 异动冷却 | 提醒防抖（默认 3 分钟），避免同一异动反复轰炸；本机提醒与邮件各自独立计时，不同列表之间也互不干扰 |

## 🧩 技术栈

- **Electron 31** + 原生 HTML / CSS / JS（**零前端框架**，包体小、无依赖地狱）
- 数据源：腾讯财经行情接口 `qt.gtimg.cn`（免费、无需注册、无需 Key）
- 邮件：**自写的零依赖 SMTP 客户端**（EHLO / STARTTLS / AUTH LOGIN / DATA），不引入 nodemailer，保证热更新链路只替换 js 文件
- 存储：纯 `config.ini`（INI 文本，`[general]` + `[email]` + 每个列表一个 `[list:xx]` 段），随程序目录走，天然便携
- 自动更新：GitHub Releases 公开 API（`releases/latest`）+ 系统安装器，不引入 electron-updater
- 打包：electron-builder（NSIS 一键安装包 / 便携包）

## 🗃 配置文件结构

`config.ini` 就放在程序目录里（安装版为 `%LOCALAPPDATA%\Programs\Marketmonitor`），可以直接用记事本改：

```ini
[general]
fetchIntervalMs=30000        ; 行情刷新间隔（所有列表共用一次请求）

[email]                      ; 全局发件账号 + 1~5 个收件槽位
enabled=true
host=smtp.qq.com
port=465
secure=true
user=you@example.com
pass=                        ; 邮箱授权码（不是登录密码）
box1=someone@example.com     ; 收件槽位 1
on1=true
box2=
on2=false                    ; 地址留着但不启用 = 临时停用
                             ; 注：v1.5.5 起「邮件阈值」已下移到各 [list:xx] 段；
                             ;     这里若还写着 followAlerts/thresholdUp/thresholdDown，
                             ;     会作为"列表段没写时"的兜底值

[list:l1]                    ; 列表 1：不含 "=" 的行 = 标的
name=自选股
width=220
height=84
mailboxes=1                  ; 这个列表发给槽位 1（写 1,3 就是发给槽位 1 和 3）
digestEnabled=true
digestIntervalMin=30
followAlerts=false           ; 邮件阈值不跟随异动 → 用下面两个单独设的值
thresholdUp=6                ; 涨 6% 才发邮件（异动仍然 3.9% 就闪屏）
thresholdDown=6
600519 贵州茅台
000001 平安银行

[list:l2]                    ; 列表 2：可以盯另外一批标的
name=板块指数
width=220
height=64
mailboxes=1
followAlerts=true            ; 这个列表跟随它自己的异动阈值（改 alertUp/alertDown 即可）
thresholdUp=3.9              ; followAlerts=true 时不生效，仅作切回"单独设"时的记忆值
thresholdDown=3.9
sh000001 上证指数
sz399001 深证成指
```

## ⚠️ 已知限制

- 已支持 **A 股 / 基金(ETF) / 可转债 / 港股 / 板块指数**；北交所（4 / 8 开头）仍需手动加 `sh/sz` 前缀
- 指数代码必须带前缀（`sh000001`）——只写 `000001` 会被识别成平安银行 `sz000001`
- 港股代码为 5 位（`00981`）；只写 3~4 位（`981`）时不会自动判市场，请写 `hk981` 或用拼音搜索选候选
- 港股只收录**正股**，窝轮 / 牛熊证等衍生品会在搜索里过滤掉
- 邮件推送需要你的邮箱**开启 SMTP 服务并生成授权码**（不是登录密码）：QQ / 163 等在邮箱「设置 → 账户」里开启。发送结果写在程序目录 `maillog.txt`，失败原因见 `error.log`
- 定时汇总（「按固定时点」与「按间隔」两种方式，以及收盘总结）**统一只在开盘窗口内推送**：上午 09:25–11:35、下午 13:00–15:05；11:35–13:00 午休、收盘后与夜间都不会推（v1.5.6 起「按间隔」模式也受同一时间窗约束，此前它不受限、收盘后会一直发到关程序为止）。程序每 30 秒刷新一次行情，实际发出时间会有最多 30 秒偏差
- 「按固定时点」模式下，某个时点没赶上（电脑休眠 / 程序没开）会在**同一个交易时段内**补推最近一次，例如 10:00 开机补 09:55、14:40 开机补 14:35；跨交易时段不补，晚上开机也不会补推早上的汇总。同一个时点当天只推一次，程序重启也不会重复
- 每个列表的定时汇总**各自独立计时**；同一个列表的行情只发一封，不会因为多个窗口而重复发送
- 自动更新走 GitHub Releases：**需要能访问 github.com**（国内网络可能较慢）；下载后由系统安装向导完成覆盖，程序不会静默替换正在运行的 exe
- 监控列表上限 6 个（窗口太多既挤屏幕也容易误操作）
- 程序**单实例运行**：重复双击图标 / 点开始菜单不会开出第二个进程，只会把已有窗口和设置页唤到前台（两个进程同时跑会互相覆盖配置）
- 托盘「显示全部小组件」**不会**打开已被关掉（设置里取消「启动时显示」）的列表；想让某个列表回来，请用托盘「监控列表 → 该列表 → 显示」
- 列表位置规则：**手动拖过的列表永远记住你的摆放**（除非坐标跑到屏幕外，如换了显示器）；没拖过的列表按列表顺序自动堆叠，第一次启动新版时会被重新排一次
- 停牌股票显示最后一次有效数据
- 无网络时占位为 `--`，恢复后自动刷新
- 仅在 Windows x64 上验证过；macOS / Linux 未专门适配（透明无边框窗口行为可能有差异）

## ❤️ 写在最后

**这是 AI 从零搓出来的程序。**

从最初只有两行滚动的简陋卡片，到现在的异动提醒、透明度、尺寸双向调节、九宫格定位、一键安装包——每一条功能都是 AI 一步步落地、再反复修 bug 磨出来的。
